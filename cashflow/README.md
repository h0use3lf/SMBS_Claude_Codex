# 개인 현금흐름 관리 (CashFlow)

한 달 예산을 세우고 2주 단위로 현금흐름을 기록·결산해, 제출용 보고서(Word + Excel → PDF 1개)를 만드는 PySide6 데스크톱 프로그램입니다. 금융 관리를 처음 하는 20대 대학생 과제용으로 만들었습니다.

## 주요 기능

- **지난 기록으로 자동 산출**: 시작점(날짜·그날 가용 현금)과 지난 기간 기록(최소 2주)을 입력하면 기초 잔액, 변동지출 배분 비율, 수입·저축·고정지출 계획을 역산 (수정 가능)
- **예산 3개 안**: 보수안·균형안·적극안 중 선택 → 한 달 예산을 평일·휴일 일수와 예정 일정 기준으로 2주씩 분할 (단순 절반 분할 아님)
- **자동 분류 기록**: 항목명만 입력하면 종류·카테고리·계획 여부 자동 분류, 분류를 바꾸면 학습
- **결산**: 기간별 예산 대비 실적, 카테고리·평일/휴일·계획/비계획 분석, 유지·조정·중단 분류, 일별 잔액
- **보고서 출력**: 재무상태표·현금흐름표를 포함한 Word 보고서 + 수식 포함 Excel 부속명세서 → PDF로 병합

## 실행

```
pip install -r requirements.txt
python main.py
```

또는 `run.bat` 더블클릭. 사용 순서는 `사용법.txt` 참고.

## exe로 빌드

```
build.bat
```

`dist\CashFlow.exe`가 생성됩니다. torch·scipy 등 다른 패키지가 많이 설치된 Python에서 빌드하면 exe가 커지고 시작이 느려지므로, requirements.txt만 설치한 가상환경에서 빌드하는 것을 권장합니다.

## 참고

- PDF 변환에는 MS Office(Word·Excel) 또는 LibreOffice가 필요합니다.
- 입력 데이터는 `문서\현금흐름관리\data.json`에 자동 저장됩니다.
