개인 현금흐름 관리 프로그램

[설치·실행 (Windows)]
1. Python 3.10 이상 설치 (python.org, 설치 시 "Add python.exe to PATH" 체크)
2. run.bat 더블클릭 → 바로 실행
   또는 build.bat 더블클릭 → dist\CashFlow.exe 생성 (이후 exe 하나로 실행·배포)
3. PDF 변환에는 MS Office(Word·Excel) 또는 LibreOffice가 필요합니다.

[사용 순서]
01 기본 정보   인적 사항, 생활 형태·소득·관리 대상, 기록 기간, 기초 재무상태 입력
02 예산 수립   지난 기간 기록(최소 2주)과 시작점(날짜·잔액) 입력 → [지난 기록으로 산출]로 기초 잔액·배분 비율·
               수입·저축·고정지출 역산(수정 가능) → 예정 일정 입력 → [산출] → 3개 안 중 하나 선택
03 기록        결제 직후 항목·금액 입력(Enter) → 종류·카테고리·계획 여부 자동 분류
04 결산        기간별 예산 대비 실적 확인, 기간 말 실제 잔액 입력, 차이 해석 작성
05 평가·원칙   한계, 절약 목표(결산 기반 초안 → 수정), 느낀 점, 관리 원칙 작성
06 보고서 출력 Excel 부속명세서 + Word 보고서 → 제출용 PDF 1개로 병합

[데이터]
입력 내용은 문서\현금흐름관리\data.json 에 자동 저장됩니다.
