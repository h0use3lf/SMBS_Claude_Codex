# 보드게임 현황판 편집기

캐비닛 4개 × 칸 5개짜리 보드게임 보관함의 목록을 화면에서 입력/수정하고, 인쇄용 엑셀(칸별 목록표)을 자동으로 만들어주는 Tkinter 데스크톱 프로그램입니다.

## 주요 기능

- 캐비닛 1~4, 칸 1~5를 트리에서 선택해 게임 목록을 `게임명,수량` 형식으로 한 줄씩 입력/수정
- **데이터 저장은 엑셀과 분리**: 실제 데이터는 프로그램(exe) 옆에 자동 생성되는 로컬 데이터베이스(`보드게임_데이터.json`)에 저장됩니다. 작업자나 컴퓨터가 바뀌어도 그 컴퓨터에 데이터베이스가 없으면 내장된 기본 데이터로 새로 시작하고, 그 이후부터는 그 컴퓨터의 로컬 데이터베이스를 자동으로 불러옵니다.
- "엑셀로 내보내기": 현재 데이터를 인쇄용 엑셀(캐비닛 1~4 시트)로 생성. 한 칸의 목록이 한 페이지(45줄)를 넘으면 절대 중간에서 자르지 않고 통째로 다음 페이지로 넘깁니다.
- "엑셀에서 가져오기": 기존 인쇄용 엑셀 파일의 데이터를 불러와 현재 작업 내용을 교체
- 저장 시 인쇄용 엑셀 파일명에 그날 날짜가 자동으로 붙습니다 (`보드게임 현황표 26_03_12.xlsx` 형식)

## 실행

```
pip install -r requirements.txt
python 보드게임_현황판_편집기.py
```

## exe로 빌드

```
build.bat
```

`dist\보드게임_현황판_편집기.exe`가 생성됩니다. PyInstaller가 필요합니다 (`pip install pyinstaller`).

## 참고

- 이 저장소는 공개 저장소라서, 코드 안의 `DEFAULT_DATA`(새 컴퓨터에서 처음 실행할 때 채워 넣는 기본 데이터)는 비워뒀습니다. 그대로 실행하면 빈 상태로 시작하며, 데이터는 화면에서 입력하거나 `엑셀에서 가져오기`로 채우면 됩니다.
- 인쇄용 시트의 머리글 폰트는 `ONE 모바일POP`을 사용합니다. 해당 폰트가 없는 PC에서는 기본 폰트로 자동 대체됩니다.
